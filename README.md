# LeetCode Practice — Java

A collection of Java solutions to coding interview and data-structures-and-algorithms problems.

## Problem Areas

The current `src/Easy/` directory includes solutions covering problems such as:

- Two Sum
- Palindrome Number
- Roman to Integer
- Longest Common Prefix
- Valid Parentheses
- Remove Duplicates from Sorted Array
- Remove Element

## Approach

Each problem is kept in a focused Java source file to make individual solutions easy to find, run and review. The repository is a learning log; solutions may be refined as understanding and implementation choices improve.

## Technology

- **Language:** Java
- **IDE metadata:** IntelliJ IDEA project file is included

## Run Locally

1. Install a Java Development Kit (JDK).
2. Clone the repository:
   ```bash
   git clone https://github.com/MihailKanev01/LeetCode.git
   cd LeetCode
   ```
3. Open the project in IntelliJ IDEA, or compile a chosen solution from `src/` after checking its class and package declaration.

## Project Status

An ongoing practice repository. The goal is to improve problem-solving skills, code clarity and algorithmic thinking over time.
